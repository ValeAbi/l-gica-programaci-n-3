# Factorial en JavaScript

Programa que pide un número por `prompt`, valida que sea un entero mayor o igual a 0 y calcula su factorial. El resultado se muestra por consola y en la página.

## Cómo usarlo

1. Abre `index.html` en el navegador.
2. Escribe un número en la ventana emergente.
3. Mira el resultado en la página o en la consola (`F12`).

## Ejemplos

- 5 → 120
- 6 → 720
- "hola" → error y vuelve a pedir el número

## Archivos

- `index.html`
- `script.js`
